# 학사 서비스 디자인 정리 — 2026-09-22

## 범위

- 참고: [서울대학교 경영대학](https://cba.snu.ac.kr/). 실제 화면을 확인하고 짙은 파란색, 여백, 얇은 구분선, 절제된 카드 스타일을 참고했다. 사진·영상·본문은 복제하지 않았다.
- 변경 파일: app/globals.css, app/page.tsx, components/brand.tsx, e2e/visual-refresh.spec.ts.
- 기존 소개 문구·역할 카드 3개·경로·탭 순서·폼·도메인 규칙·데이터·저장 방식은 그대로 유지했다.
- 전체 배경은 미색, 주요 색은 기존 SNU Blue 유지. 둥근 모서리와 그림자를 줄이고 제목·구분선·여백을 정돈했다.
- 첫 화면은 기존 콘텐츠 순서를 유지하면서 남색 소개 영역과 역할 카드를 스타일링했다.
- 샤 심볼은 원본 PNG를 수정하지 않고 CSS mix-blend-mode: multiply로 밝은 화면 배경과 합성하여 흰 사각형이 보이지 않게 했다. PNG 자체를 투명 이미지로 변환한 것은 아니며 파비콘은 기존 원본 그대로다.

## 검증

- Vitest 63개 통과, Playwright 전체 E2E 29개 통과, npm run build 통과.
- 375px·1440px에서 첫 화면 및 학생·교수·조교 화면 캡처. 가로 넘침 없음, 링크·탭·심볼 렌더링 검증.
- 기존 신청·승인·면담·제출·절차 편집 E2E 유지 및 통과.
- 의존성 설치 시 moderate 감사 경고 11건이 보고됨. 디자인 요청 범위 밖이므로 의존성 변경은 하지 않았다.
- 공식 서비스 또는 심볼 사용 승인을 의미하지 않는다. 심볼 출처와 사용 안내는 public/BRAND-SOURCE.md 참고.
