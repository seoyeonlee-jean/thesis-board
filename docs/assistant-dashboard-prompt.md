# 학과 조교 대시보드 UI 프롬프트

기존 학과별 절차 데이터와 게시·임시저장 기능을 유지하면서 다음 규칙을 적용한다.

- 단계 추가·삭제를 지원한다. 단계 순서는 고정하며, 정렬·위아래 이동 기능은 제공하지 않는다.
- 새 단계는 목록의 마지막에 추가한다.
- 드래그 핸들, 드래그 이벤트, 위/아래 버튼과 순서 변경 로직을 두지 않는다.
- 진입 시 왼쪽 절차 편집기와 오른쪽 학생 미리보기의 모든 단계를 접는다.
- 왼쪽 단계 카드에는 단계명·기간·진행 방식과 삭제 버튼을 표시한다. 필요한 단계의 '단계 설정'을 펼쳐 수정한다.
- 왼쪽 요약 날짜는 '2026. 10. 02. 18:00'처럼 연도·두 자리 월일·24시간제로 표시한다. 날짜 입력은 브라우저의 날짜 선택기를 유지한다.
- 오른쪽 학생용 마감은 '10월 2일 18:00까지'로 표시한다. 조건부 마감은 조건명과 함께 같은 형식을 쓴다.
- 날짜가 없으면 '정보 확인 필요'를 표시한다. 가정 날짜의 '예정값' 배지는 조교 화면에서만 제공한다.
- 조교는 절차·공지 게시 및 소속 학생 진행 조회만 수행하며, 지도교수 배정·승인·정원 변경 기능은 제공하지 않는다.

## 교수 화면 추가 규칙

- 기본 탭은 '내 지도 학생'이다. 알림 등의 명시적인 탭 링크가 있으면 해당 탭을 연다.
